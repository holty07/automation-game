Automation Game is a 2D tile-based game where you perform tasks by hand, record what you did, and hand the recording to a robot that replays it forever — the recording becomes an editable instruction list you can reorder, edit and extend as your automation grows more sophisticated. Install dependencies with `pnpm install`, then run `pnpm dev` to launch the Vite dev server, `pnpm verify` to typecheck, lint and test the project, and `pnpm sim -- --fixture tests/fixtures/empty-world.json --ticks 100` to run the simulation headlessly and print a text dump of the world state.
